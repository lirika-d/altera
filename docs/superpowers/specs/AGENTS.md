# Design: универсальный `AGENTS.md`

## Намерение

Добавить в корень ALTERA переносимый файл `AGENTS.md` с подробными, но применимыми к разным языкам и стекам правилами для ИИ-агентов. Пользователь вручную перенесёт его в другие проекты.

## Цели и ограничения

- Перед изменениями агент изучает инструкции, документацию и релевантный код конкретного проекта; не выдумывает неизвестное.
- Уточнения нужны для решений, которые заметно влияют на результат; малые и полностью описанные задачи не блокируются формальностями.
- Агент сохраняет существующие изменения и данные, придерживается архитектуры проекта, делает только запрошенный объём работы и проверяет результат подходящими проекту средствами.
- Ответы пользователю — на русском; отчёт явно отделяет выполненные проверки от непроверенного и оставшихся рисков.
- Документ не задаёт стек, команды, архитектуру ALTERA или процессы конкретного репозитория и не дублирует `README.md`/`PROJECT_CONTEXT.md`.
- Создаётся только новый `AGENTS.md`; другие текущие незакоммиченные изменения не затрагиваются. Commit/push не выполняются.

## Подходы

- **Короткая памятка:** проще читать, но недостаточно подробно фиксирует защиту данных, проверки и обработку неопределённости.
- **Подробная универсальная инструкция — выбрано пользователем:** полнее задаёт рабочий цикл и защитные правила, оставаясь независимой от стека и допускающей лёгкие задачи без бюрократии.

## Критерии готовности

`AGENTS.md` понятен без контекста ALTERA, помогает агенту сначала исследовать любой репозиторий, явно защищает пользовательские данные/изменения, задаёт соразмерные проверки и не обещает непроведённых тестов. После прочтения документа пользователь подтверждает его перед реализацией.

## Допущения

Файл останется в `C:\Users\Admin\Downloads\ALTERA` как источник для ручного переноса. Для его автоматического действия в других репозиториях пользователь сам скопирует файл туда.
